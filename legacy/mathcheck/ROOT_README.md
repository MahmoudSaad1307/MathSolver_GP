# 🧮 MathCheck | المصحح الرياضي الذكي

تطبيق محلي عالي الدقة مبني بلغة بايثون وواجهة Streamlit مخصصة باللغة العربية (RTL) لحل المسائل الرياضية خطوة بخطوة، وفحص خطوات الحل المكتوبة بخط اليد من صورة، وتحديد **الخطوة الخاطئة الأولى بدقة** وشرح سبب الخطأ والقاعدة المنتهكة.

---

## 🏛️ المبدأ الجوهري (Core Invariant)

> **النموذج اللغوي (LLM) ليس حكماً على صحة الرياضيات إطلاقاً. الحكم الوحيد والنهائي هو محرك الجبر الرمزي SymPy.**

ينحصر دور نماذج الذكاء الاصطناعي في 3 مهام فقط:
1. **قراءة الصورة (OCR):** نسخ الخطوات كما كُتبت تماماً دون تصحيح أو حل.
2. **اقتراح خطوات الحل:** تقسيم الحل إلى خطوات جبرية مفردة.
3. **شرح الخطأ باللغة العربية:** صياغة التفسير اللغوي للمغالطة الرياضية بالعامية المصرية المبسطة بناءً على مرجع رمزي موثوق ومحسوب مسبقاً بواسطة SymPy.

أي خطوة لا يستطيع SymPy تأكيد صحتها حسابياً تُصنّف فوراً كـ `unknown` (غير قابلة للتحقق)، ولا تُقبل أبداً كـ `ok`.

## 📁 هيكلية المشروع

```
mathcheck/
  app.py                  # واجهة Streamlit (عرض فقط، خالية من منطق الأعمال)
  core/
    parsing.py            # تحويل النصوص إلى تعابير SymPy، دعم الجذور المتعددة ';' والمعادلات التفاضلية
    verify.py             # محرك التحقق الجبري check_step، فحص السلاسل، وأخذ العينات العددية (14 عينة كسرية)
    solve.py              # حلقة الحل الآمن (LLM + تحقق SymPy + إعادة المحاولة)
    check.py              # فحص خطوات الطالب وتحديد أول خطوة خاطئة
    simple_modes.py       # حاسبة رمزية مباشرة (حل معادلات، اشتقاق، تكامل، معادلات تفاضلية)
  llm/
    client.py             # عميل Groq، معالجة خطأ 429، التراجع بين النماذج، واستخراج JSON بأمان
    ocr.py                # معالجة الصور، قراءة بنموذجين، ونظام التنبيهات والتحذيرات
    prompts.py            # قوالب التوجيه الصارمة لـ OCR والحل والشرح
    ollama_fallback.py    # عميل Ollama المحلي للطوارئ أو وضع الخصوصية الكاملة
  config.py               # إدارة الإعدادات والتحقق السريع
  tests/
    test_parsing.py       # اختبارات التحليل والرموز
    test_verify.py        # اختبارات الفحص الجبري والعينات
    test_check.py         # اختبارات رصد الأخطاء والتسلسل
    test_solve.py         # اختبارات حلقة الحل وإعادة المحاولة
    test_ocr_flags.py     # اختبارات تنبيهات واختلاف نماذج القراءة
  .env.example            # نموذج المتغيرات البيئية
  requirements.txt        # الحزم المطلوبة مثبتة الإصدارات
  README.md               # التوثيق الشامل
```

## 🚀 التثبيت والتشغيل السريع

### 1. المتطلبات الأساسية
- مثبت **Python 3.11** أو **3.12**.
- نظام تشغيل Windows / Linux / macOS.

### 2. تثبيت الحزم المطلوبة
افتح الطرفية (Terminal أو PowerShell) في مجلد المشروع ونفّذ:

```bash
pip install -r requirements.txt
```
*(أو باستخدام مشغل بايثون في ويندوز: `py -3.12 -m pip install -r requirements.txt`)*

### 3. إعداد ملف البيئة `.env`
انسخ ملف `.env.example` إلى `.env`:

```bash
cp .env.example .env
```

ضع مفتاح Groq الخاص بك في السطر:
```env
GROQ_API_KEY=gsk_your_actual_key_here
```

> [!IMPORTANT]
> **التحقق من معرفات النماذج (Model IDs):**
> تتغير معرفات النماذج في منصة Groq دورياً. يمكنك دائماً مراجعة النماذج النشطة عبر:
> 👉 [console.groq.com/docs/models](https://console.groq.com/docs/models)
> النماذج المعرفة افتراضياً في `.env`:
> - للرؤية وقراءة الصور: `qwen/qwen3.8-27b,qwen/qwen3.6-27b,meta-llama/llama-4-scout-17b-16e-instruct`
> - للاستنتاج والحل: `openai/gpt-oss-120b,qwen/qwen3.8-27b,qwen/qwen3.6-27b`

### 4. تشغيل التطبيق محلياً
من داخل مجلد `mathcheck` (أو المجلد الرئيسي):

```bash
cd mathcheck
streamlit run app.py
```

### 📱 تشغيل التطبيق واستخدامه من الهاتف عبر نفس شبكة الـ Wi-Fi
لتتمكن من تصوير كشكول الحل مباشرة بكاميرا هاتفك ومراجعته على شاشة الهاتف:

```bash
cd mathcheck
streamlit run app.py --server.address 0.0.0.0
```

سيظهر لك في شاشة الطرفية عنوان الشبكة المحلية (مثل `http://192.168.1.X:8501`). افتح هذا الرابط في متصفح هاتفك المحمول المتصل بنفس الشبكة.

## 🔒 ملاحظة الخصوصية والتشغيل دون إنترنت (Ollama Local Mode)

- عند استخدام Groq، تُرسل صور المسائل واستفسارات النصوص إلى خوادم Groq السحابية الفائقة السرعة.
- إذا كنت تتعامل مع مواد امتحانية خاصة أو بيانات حساسة، يمكنك تفعيل **الوضع المحلي بالكامل** بتعديل السطر التالي في ملف `.env`:
  ```env
  USE_GROQ=false
  ```
- في هذا الوضع، لن يخرج أي طلب إلى الإنترنت نهائياً؛ سيعتمد التطبيق بالكامل على خادم **Ollama** المحلي ونموذج `qwen2.5vl:7b` للرؤية و `qwen2.5:7b` للاستنتاج.
- تأكد من تثبيت وتشغيل Ollama وتحميل النماذج عبر:
  ```bash
  ollama run qwen2.5vl:7b
  ollama run qwen2.5:7b
  ```

## 🧪 تشغيل حزمة الاختبارات الشاملة (Unit Tests)

جميع الاختبارات معزولة بالكامل وتستخدم محاكاة (Mocking) لطبقة الـ LLM لضمان عملها دون إنترنت:

```bash
py -3.12 -m pytest mathcheck/tests -v
```

تشمل الاختبارات:
- التعرف على الضرب الضمني `2x` وقوى المتغيرات `x^2` والجذور المتعددة `x = 2; x = -3`.
- تحويل مشتقات المعادلات التفاضلية `y'' + y = 0` و `y' - 2y = 0`.
- كشف التحليل الخاطئ للمقادير (مثل إشارة الخطأ `x^2 - 5x + 6 = 0 -> (x-2)(x+3)=0`).
- التحقق من تكافؤ التكامل غير المحدد عند اختلاف ثابت التكامل (+C).
- كشف نسيان طرف المعادلة `= 0`.
- سلسلة حل مكونة من 4 خطوات مع رصد الخطأ في الخطوة 3 وتصنيف الخطوة 4 كـ "مبنية على خطأ سابق".
- حلقة إعادة المحاولة لنموذج الحل حتى النجاح.
- تنبيهات اختلاف القراءة بين نموذجي الرؤية، والأسطر غير القابلة للقراءة، والقارئ الفردي.

## ⚠️ القيود الفنية المعروفة (Known Limitations)

1. **التعرف البصري على خط اليد (OCR):** يظل التعرف على الكتابة اليدوية غير الواضحة أو المشوهة هو الحلقة الأضعف في أي نظام ذكاء اصطناعي. للتغلب على ذلك، يوظف MathCheck نظام القراءة المزدوجة بنموذجين مختلفين، ويضع تنبيهات فورية، ولا يسمح بالتشغيل إلا بعد مراجعة الطالب للخطوات في مربع النص القابل للتعديل.
2. **المسائل الكلامية والإثباتات النظرية:** الخطوات التي لا تحتوي على تعبيرات رياضية قابلة للاختزال الجبري الرمزي تُصنف تلقائياً كـ `unknown` أو `skip`؛ لا يقوم SymPy بادعاء صحتها أو خطئها دون برهان جبري قاطع.
3. **المعادلات التفاضلية المعقدة:** يتم التحقق التام من حلول المعادلات التفاضلية النهائية بالتعويض في المعادلة الأصلية عبر `sp.checkodesol`. الخطوات الوسيطة غير القابلة للحل المباشر قد تعود بـ `unknown`.
